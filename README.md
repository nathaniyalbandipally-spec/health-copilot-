# AI Health Copilot 🏥

An AI-powered personal healthcare assistant.

## Features
- Medical Record Intelligence and OCR
- AI Health Summary in Simple Language
- Unified Health Profile and Timeline
- English and Telugu Support
- Mock ABHA Linking
- FHIR R4-style Health Records
